## 🚀 Featured Project

### [Intelligent Task Allocation System (ITAS)](https://github.com/Abumarar/Intelligent-Task-Allocation-System-ITAS-)
**A smart solution for automated project management.**

ITAS is a web-based application designed to automate the assignment of tasks within software projects. By leveraging **Natural Language Processing (NLP)**, it analyzes team members' CVs and portfolios against specific task requirements to ensure the perfect skill-based match.

* **Core Features:** Automated CV analysis, skill matching, and task distribution.
* **Tech Stack:** Python, NLP, Web Technologies.
